# SIDELINE 26 ⚽

Eigenständiger mobiler Fußballmanager mit unbegrenzten Münzen und lokalen Spielständen.

- Transfers, Kader, Aufstellung und Taktik
- Live-Spieltage, Tabelle, zehn Teams und Saisonwechsel
- Trainingszentrum, Stadion, Vereinsausbau, Sponsoren
- Spielstand-Export/Import, offline-fähige PWA

GitHub Pages: https://jan-jarre-pixel.github.io/sideline26/ (nach Aktivierung)

Pages aktivieren: Settings > Pages > Deploy from a branch > main > /(root) > Save.

Inoffizieller eigenständiger Prototyp. Keine Verbindung zu FIRE UP oder Kaypora Games.
